# 通义千问 知识库

> **通义千问（Qwen）** —— 阿里云的双轮战略：开源模型全球下载领先 + 百炼平台企业级 Agent 服务，是"开源 + 云"路线的中国代表。

## 核心能力

- **Qwen 开源模型**：Qwen2.5 / Qwen3 系列全球下载量领先，覆盖 0.5B~1000B+ 全尺寸
- **Qwen Code / Qwen Agent**：编程与 Agent 能力持续增强
- **百炼平台（Model Studio）**：企业级模型调用 + 智能体编排 + RAG 应用搭建
- **通义 App**：个人助手入口
- **阿里云生态**：与函数计算、数据库、大数据深度集成
