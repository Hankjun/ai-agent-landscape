# 腾讯元宝 知识库

> **腾讯元宝** —— 腾讯混元驱动的 AI 助手。微信生态的天然入口 + 智能体创作平台，是"社交生态 + Agent"路线的代表。

## 核心能力

- **元宝 App**：腾讯官方 AI 助手，微信/QQ 生态内嵌入口
- **智能体创作**：元宝内智能体广场 + 创作工具，个人可发布自己的 Agent
- **混元大模型**：腾讯自研基座模型，多模态
- **微信生态联动**：公众号内容理解、小程序工具调用
- **企业侧**：腾讯云智能体平台 + 混元 API
