# Codex 知识库

> **Codex** —— OpenAI 的编程 Agent。Codex CLI 开源 + 云端并行任务执行，直接竞争 Claude Code 与 Gemini CLI，是"ChatGPT 世界的开发者入口"。

## 核心能力

- **Codex CLI**：终端 Agent，开源（Apache-2.0），支持本地与云端执行
- **云端 Agent**：ChatGPT 内的 Codex，可并行处理多个任务、操作 GitHub
- **任务并行**：多任务同时推进，完成后汇总
- **ChatGPT 深度集成**：与对话、文件、工作区打通
- **MCP 支持**：接入 MCP 服务器扩展工具链

## Challenge / 实战

- **Codex CLI 安装即用**：`npm install -g @openai/codex`，让它完成一个真实代码任务
- **云端并行**：在 ChatGPT 中给 Codex 派发 5 个 GitHub issue，观察并行处理
- **Agent 对比评测**：同一任务分别用 Codex / Claude Code / Gemini CLI 跑，记录差异
