> **Gemini** —— Google 的旗舰 AI 智能体。Gemini CLI、A2A 协议、超长上下文与谷歌全家桶深度集成，是 Agent 时代的"搜索级基础设施"玩家。

## 核心能力

- **Gemini CLI**：终端编程 Agent，支持 Agent2Agent（A2A）协议与 MCP
- **超长上下文**：百万级 token 上下文窗口，整库级文档处理
- **Deep Research**：自动化的多步研究 Agent，输出研究报告
- **A2A 协议**：Agent2Agent，Google 推动的 Agent 间通信标准
- **谷歌生态集成**：Gmail / Calendar / Maps / Drive / Search / YouTube
- **AI Studio / Gemini API**：免费额度充足的开发平台
