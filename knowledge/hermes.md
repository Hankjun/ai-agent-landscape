## 核心能力

- **长程自主**：一次任务可执行数十个工具调用，跨会话持续工作
- **工具调用**：终端、文件、网页、搜索、定时任务（Cron）、语音等
- **多平台接入**：CLI / 桌面 App / Telegram / WhatsApp / Discord / Slack / Signal / 邮件
- **技能体系（Skills）**：可复用的程序性记忆，跨会话积累
- **记忆系统**：持久记忆 + 用户画像，跨会话上下文延续
- **可自托管**：本地部署，数据自持；支持多种模型提供商（含本地模型）

## Challenge / 实战

- **自己跑一个 Hermes**：本地部署（pip / docker / 二进制），接入你常用的模型，完成一次真实工作流（如"自动抓取行业资讯并生成简报"）
- **写一个技能**：把你在用的一个重复性流程固化成 SKILL.md
- **多 Agent 协作**：用 Cron + 多会话编排一个 7×24 自动运行的监测任务
