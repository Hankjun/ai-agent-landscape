# 豆包 知识库

> **豆包** —— 字节跳动的超级 AI 入口。豆包 App 亿级用户 + 扣子（Coze）Agent 平台 + 火山方舟模型服务，构成字节 Agent 生态的三层结构。

## 核心能力

- **豆包 App**：亿级 DAU 的通用助手，语音、多模态、浏览器插件
- **扣子（Coze）**：低代码 Agent 搭建平台，插件市场 + 工作流 + 知识库，国内/海外双版本
- **火山方舟（Ark）**：模型推理服务，豆包模型 API + 智能体云服务
- **即梦**：文生图/视频创作 Agent 生态
- **多模态**：图像、语音、视频理解生成一体
