## 核心能力

- **Kimi 智能助手**：超长上下文处理（百万级），文件解析、联网搜索
- **Kimi CLI / Kimi For Coding**：编程 Agent 能力
- **K2 开源模型**：Moonshot 开源基座模型，MoE 架构
- **Kimi K2 Thinking**：推理模型系列
- **开放平台**：Moonshot API 服务
